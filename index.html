🏦 API de Banxico — Tipo de Cambio DOF

📋 ¿Para qué sirve?
Configura tu token gratuito de Banxico para que la app actualice automáticamente el TC del DOF (serie SF43718 — USD/MXN FIX), que es el oficial para facturación SAT.
🔑 ¿Cómo obtener el token?
1. Entra a www.banxico.org.mx/SieAPIRest/service/v1/token
2. Llena el formulario (es gratis)
3. Recibirás el token por correo
4. Pégalo aquí abajo y guarda
El token se guarda solo en tu navegador. No se comparte.
